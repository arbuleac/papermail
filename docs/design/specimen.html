SuperSparrow design language · Quire 1.8.4 · 7 November 2026

Quire — mail, set like a page.

Each conversation is a gathering of folded messages and one open sheet, set in New York on warm paper and marked in a single ink, Iron Gall. The list is a still index; the reader gets the room of a page. Every colour, size and duration on this sheet is a custom property generated from docs/design/tokens.json.

  1. Reading is the product.Serif where people read, sans where they scan or write.
  2. One ink, used like a pen.Iron Gall marks unread, selection, focus and the one primary action.
  3. A still list, a generous page.Rows never move or blur; motion is short, rare and interruptible.
  4. Shape before colour.Every state has a shape, a weight or a word.
  5. Native first, then ours.Traffic lights, menus, alerts and notifications stay macOS.
A · Main window

Unified inbox, list driving

1280 × 800 pt, window key. Three accounts. The selection keeps its Iron Gall wash and margin rule while the main window is key, wherever the first responder is.
