Cheat sheet overlay layout.cheatSheet · cheatSheetContent · scrim

An in-window overlay, not a system sheet: scrim over the window (scrimSolid, opaque, under Reduce Transparency), focus trapped in the panel, single keys swallowed. Esc, ?, ⌘/, ⌘W, the close button or a click on the scrim dismisses it. The content is the whole key map in two bands of three sections, sentence case, drawn from cheatSheetContent; {{layout.cheatSheet.width}} × 604 pt, so it fits the default window whole.
