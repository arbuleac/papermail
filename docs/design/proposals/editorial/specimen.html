SuperSparrow · Design language proposal · Editorial direction

Quire — mail, set like a page.

A quire is a gathering of folded sheets, the unit a book is sewn from. Quire treats each conversation the same way: a tight stack of folded messages and one open sheet, set in New York on warm paper, marked in a single ink called Iron Gall.

  1. Reading is the product.Serif where people read, sans where they scan or write.
  2. One ink, used like a proofreader.Iron Gall marks only what needs you: unread, focus, the one primary action.
  3. Still list, generous page.The list is compact and never moves. The reader breathes.
  4. Shape before colour.Every state has a shape, weight or word, so colour is never the only cue.
